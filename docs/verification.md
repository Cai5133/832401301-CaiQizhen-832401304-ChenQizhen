## 浏览器实际操作

使用独立的本地虚构数据 HTTP 服务验证，不是正式后端验收。

| 场景 | 实际结果 |
| --- | --- |
| 空姓名保存 | 显示必填错误并聚焦姓名，未关闭弹窗 |
| 同一人两个电话和邮箱 | 保存成功，详情完整显示，前导零和加号保留 |
| 错误邮箱 | 阻止保存并保留其他已填内容 |
| 编辑失败 | 模拟 503，错误可读且修改未丢失；恢复后可保存 |
| 搜索非第一条联系方式 | 邮箱能匹配联系人并自动显示详情 |
| 收藏及取消 | 星标与计数同步；收藏列表取消后条目移除，详情切到仍可见联系人 |
| 未保存退出 | 显示放弃或继续编辑提醒；放弃后原记录不变 |
| 删除 | 默认聚焦保留按钮；确认后移除联系人及更新计数 |
| 错误 Excel | 显示“未写入数据”和具体第 2 行电话列错误 |
| 正常 Excel | 显示已导入 1 位，列表重新读取；成功后不重复开放导入按钮 |
| Excel 导出 | 通过浏览器下载，读取工具成功打开；Contacts 工作表、6 列中文表头、一人一行、双电话与前导零保留 |
| 刷新失败 | 显示警告并明确保留上次数据，不伪装刷新成功 |
| 手机宽度 390 | 页面无横向溢出；表单左右边界在视口内，能聚焦姓名并 Escape 关闭 |

截图保存在本机前端审阅输出目录，方便查看。

## 英文界面复核

已移除侧栏底部课程项目标识；页面、弹窗、占位文案、校验、通知与导入错误反馈统一为英文。仅将本地虚构演示数据改为英文，不翻译用户真实联系人资料。保留既定 API 字段、Excel 表头与工作表格式，界面英文说明要求沿用下载模板。
