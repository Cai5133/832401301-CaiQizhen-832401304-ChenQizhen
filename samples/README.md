# Excel 格式 v1

必须是真正的 .xlsx，工作表 Contacts，第 1 行固定表头，后续每个联系人一行。

| 姓名 | 收藏 | 电话 | 邮箱 | 社交账号 | 地址 |
| --- | --- | --- | --- | --- | --- |
| 测试联系人甲 | 1 | ["13800000000","01012345678"] | ["demo@example.com"] | ["demo_social"] | ["示例市示例路1号"] |

姓名必填，收藏填 1 或 0。多值列使用 JSON 字符串数组，空白或 [] 视为空数组。电话按文本保留前导零，不按地址内的逗号拆分数据。

同名允许，导入为新增；重复上传再次新增。任何一行错误整批不写入，返回行号、列名和原因。后端限制 5 MB、5000 条，最多扫描 10000 行，解压后总量 50 MB；前端须保持一致。

label 是可选界面备注，Excel v1 不保存；所有联系方式 value 必须完整往返。样例数据全部虚构。以下文件由后端生成器提供，与接口使用同一套工作簿生成逻辑。

## 文件与预期结果

| 文件 | 用途与预期 |
| --- | --- |
| template.xlsx | 一位虚构示例，多电话、多邮箱；成功导入 1 条 |
| normal.xlsx | 4 位联系人，含同名、收藏、中文、国际号码和空方式；导入 4 条 |
| invalid/missing-header.xlsx | 错误表头，422，第 1 行 |
| invalid/invalid-favorite.xlsx | 收藏为 2，422，第 2 行收藏列 |
| invalid/invalid-json.xlsx | 电话数组含数字，422，第 2 行电话列 |
| invalid/empty-name.xlsx | 空姓名，422，第 2 行姓名列 |
| invalid/formula.xlsx | 姓名单元格为公式，422，第 2 行 |
| invalid/corrupt.xlsx | 故意损坏的文件，400 |

在 backend 执行 `python scripts/generate_samples.py` 可重新生成以上文件。异常文件专供错误处理验收，禁止作为正常模板上传。所有失败导入均不写入任何联系人。
